Selene Core isn't running = Selene Core не запущен
Selene is this theme plus its add-on, Selene Core. Install SeleneCore.pext from github.com/mattxslv/Selene/releases (open the file, or drag it onto Playnite's window), then restart Playnite. If it is installed already, make sure it is enabled under Add-ons. = Selene — это тема плюс дополнение Selene Core. Скачайте SeleneCore.pext с github.com/mattxslv/Selene/releases (откройте файл или перетащите в окно Playnite), затем перезапустите Playnite. Если уже установлено — убедитесь, что оно включено в дополнениях.
Playnite's menu still opens from here (the Start / Menu button on a controller) to pick another theme meanwhile. = Меню Playnite по-прежнему открывается отсюда (кнопка Start / Menu на контроллере), чтобы пока выбрать другую тему.
