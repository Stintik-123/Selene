# Themes and your own art

![All themes](../readme/themes-strip.jpg)

**23 color themes**, each with its own wallpaper: Selene's moonlight blue plus Catppuccin, Nord, Gruvbox, Kanagawa,
Rosé Pine, Tokyo Night and more, dark and light. Pick one per profile (edit the profile from the menu). Every screen
follows the theme; its wallpaper (or, on Selene's own theme, a breathing glow with drifting particles) shows wherever
there's no game art.

**Your own wallpapers** go in the folder set on the add-on page; they show up with the others when you choose a
background.

**Your own game art.** Put images named after the game's Playnite ID into the media folder (add-on page):
`Hero\<GameId>.jpg` for the 16:9 background art and `Square\<GameId>.jpg` for the square Spotlight tile. Without them
Selene uses the game's background and cover. The ID is in the game's Edit window in desktop mode.
