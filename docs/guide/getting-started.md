# Getting started

## Install
1. Download `Selene.pthm` and `SeleneCore.pext` from the [Releases](../../../../releases) page.
2. Open each file (or drag it onto Playnite) and confirm. Restart Playnite.
3. Fullscreen mode → **Menu → Playnite settings → Appearance → Theme → Selene**.

Selene Core only does something while the Selene theme is in use. Playnite 10 or newer, Windows 10 / 11.

## The first start
The crescent intro, then **Who's playing?** Make a profile: a name, an avatar (415 to pick from, or your own picture),
a theme and a background, previewed live on your real home. Then the **setup check** offers the add-ons Selene works
with (logos and trailers, save backups, HowLongToBeat, achievements, music), one word on each. **Install all** does
the rest; you can run it again any time from the menu.

## The controller
| Button | Spotlight | Collection | Elsewhere |
|---|---|---|---|
| **A** | Play (or open the card) | Play | Select |
| **B** | – | – | Back |
| **X** | Favorite | Details | – |
| **Y** | Move the tile or card | Game options | – |
| **LB / RB** | Filter tabs | Filter tabs | Tabs (Store, Captures) |
| **LT / RT** | Start / end of the row | – | – |
| **R3** | Trailer sound on / off | Trailer sound | – |
| **View** | Collection (hold: Find a game) | Spotlight (hold: Find a game) | – |
| **Start** | Menu (hold: Selene settings) | Menu | – |
| **Guide** | – | – | Back to the home while a game runs, and back into it |

The keyboard works too: arrows, Enter, Esc, typing in Find a game.

The hints name Xbox buttons. With **Button prompts: PlayStation** in Playnite's settings (General) they show cross,
circle, square and triangle instead.
